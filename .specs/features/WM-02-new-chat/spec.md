## Проблема

После входа пользователь не может создать чат по номеру и отправить сообщение — шаги 2–3
сценария приёмки (`.docs/requirements.md`: «вводит номер телефона получателя и создаёт новый
чат», «пишет текстовое сообщение и отправляет его»).

## Решение

- Номер → чистая нормализация в `helpers/` (пробелы, скобки, дефисы, `+`, ведущая `8` у 11 цифр
  → `7`) → 11–12 цифр. Неверный формат ловим в форме, запрос не уходит (лимит CheckAccount).
- `CheckAccount({ phoneNumber: number })` → `exist: true` → чат с ключом **числовой `chatId`**
  (skill `green-api` §5; телефон хранится только для показа). `exist: false` (по документации
  `chatId: ""`) → хук бросает `AccountNotFoundError` → «У этого номера нет аккаунта в MAX».
  Отказ приходит в UI одним путём — `mutation.error`, как в WM-01.
- Номер уже есть в списке → открываем его чат **без** `CheckAccount` (экономим лимит 100 проверок).
- `SendMessage({ chatId, message })` → исходящее в ленту из ответа по `idMessage` (без
  оптимистичного добавления: при ошибке в ленте нет «призрака»). Текст отправляется `trim()`-нутым.
- Стор `chat` (Zustand + persist `sessionStorage`, ключ `widgetmax-chat`): чаты, сообщения по
  `chatId` (дедуп по `idMessage` — пригодится WM-03 для эха), активный чат. «Выйти» стирает и
  сессию, и чаты (хук `useSignOut`).
- Раскладка по образцу web.max.ru: слева форма нового чата + список, справа шапка чата, лента,
  поле ввода снизу. Enter — отправить, Shift+Enter — перенос строки.

**Решение Димы (2026-09-29, открытое решение ресёрча §5.2):** стор `chat` хранится в
`sessionStorage` вместе с сессией. Причина: после F5 сессия остаётся — без персиста пропали бы
чаты, а WM-03 показывает ответы только для чатов, открытых в UI, и удалил бы ответ из очереди.

## Сценарии использования

1. Вводит `+7 (999) 123-45-67` → «Создать чат» → чат появился в списке и открыт.
2. Номер без MAX → «У этого номера нет аккаунта в MAX», чат не создан.
3. Некорректный номер → ошибка под полем, запроса нет.
4. Пишет текст → Enter → сообщение в ленте справа, поле очищено; пустой/пробельный текст — кнопка
   недоступна.
5. F5 → чаты и сообщения на месте; «Выйти» → вход, чатов после повторного входа нет.
