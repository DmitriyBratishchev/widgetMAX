### Ключевое решение фазы

`base: './'`, а не `'/widgetMAX/'`: один конфиг для dev, `preview` и Pages, не зависит от имени
репозитория. Деплой — только из `main` (правило окружения `github-pages` по умолчанию): сайт
появится после слияния PR `dev → main`; ручной перезапуск — `workflow_dispatch`.

### Грабли

- Порты 5173 **и 5174** заняты чужими процессами — свой dev-сервер на 5175, preview на 5176
  (`--strictPort`), чужие не трогаем.
- Git Bash переписывает аргумент `--base /widgetMAX/` в путь Windows (`C:/Program Files/Git/widgetMAX/`)
  — запуск с `MSYS_NO_PATHCONV=1`.
- `TaskStop` фонового `npx vite …` убивает обёртку, а дочерний `node` остаётся держать порт —
  перед повторным запуском проверить порт (`netstat -ano`) и командную строку процесса.
- Скрипт скриншотов (headless Edge через CDP, фейковые сессия и три чата в `sessionStorage`) — в
  scratchpad сессии, в репозиторий не кладётся; опрос уходит на несуществующий хост
  `1101.api.green-api.com` → сетевая ошибка → backoff, в UI не видно.
- `npm run test:run` в `/finish` упал: воркеры Vitest — `Fatal process out of memory: Zone` при куче
  ~45 МБ. Причина — не тесты: у машины свободно ~1,4 ГБ выделяемой памяти (commit) из 30,7 ГБ, а
  Vitest поднимает воркер на ядро. Исключено: оставшиеся headless Edge (их 0). Тот же полный набор
  с `--maxWorkers=2` — 19 файлов, 139 тестов зелёные. На CI (GitHub Actions) ограничение не нужно.
