# Команда /task-check

Приёмочный слой поверх автотестов: «тесты зелёные ≠ функционал работает» (`rules.md` §4).
Проверяет **локальную сборку текущей ветки задачи ДО слияния** в `dev`. Обычно
`/task-check` → фиксы дефектов → `/finish`.

> **Отличие от `/finish`:** `/finish` = автотесты + документация + коммит. `/task-check` =
> сверка поведения приложения с критериями `spec.md` — руками и глазами.

## Шаги

1. **Контекст задачи (текущая ветка):**
   - Текущая ветка, `git log --oneline -5`.
   - `.specs/features/{task}/spec.md` — критерии приёмки (источник строк матрицы).
   - `.specs/features/{task}/plan.md` — какие фазы реализованы.
   - `git diff --stat dev...HEAD` — какие экраны и компоненты затронуты.
   - Ресёрч эпика → «Чек-лист сквозных сценариев»: строки, которые затрагивает задача.
2. **Собрать матрицу** (шаблон ниже):
   - каждый критерий `КN` → строка «что обещано»;
   - затронутые экраны и состояния (пусто / загрузка / ошибка / узкий экран) → строки;
   - строки чек-листа эпика, которые задача могла сломать → регрессия.
3. **Разделить строки по исполнителю:**
   - **без живого инстанса** — валидация форм, состояния UI, вёрстка, поведение с отказом
     GREEN-API (неверный токен даёт 401 и на фейковых данных). Их Claude проверяет сам:
     `npm run dev` + headless-скриншот (skill `run`), смотрит на скриншоты;
   - **нужен живой инстанс** — вход реальными данными, отправка, приём ответа из MAX. Их
     проверяет **Дима**: вывести ему эти строки отдельным списком.
4. **Прогон своей части** → результат в матрицу (✓ / дефект: …).
5. **Дефекты списком** → фиксы: нетривиальные — spec-driven, с тестом (skill по зоне).
6. **Обновить `spec.md`:** подтверждённые критерии → `[x]` с доказательством («скриншот
   localhost: …», «проверено Димой на инстансе: …»). Чего не проверяли — не отмечать.
7. Если есть ресёрч эпика — **дописать новые экраны/поведение** задачи в «Чек-лист сквозных
   сценариев».

## Шаблон матрицы

```
| # | Критерий/фича | Экран / состояние | Проверить (действие → ожидание) | Кто | Результат |
```

- **Критерий/фича** — `КN` из `spec.md` или строка чек-листа эпика.
- **Экран / состояние** — вход, список чатов, лента; пусто / загрузка / ошибка; ширина 375 / ≥1024.
- **Кто** — `Claude` (локально, без инстанса) | `Дима` (живой инстанс).
- **Результат** — ✓ / дефект: …

## Что дальше

Дефектов нет, строки Димы пройдены → **`/finish`** (последняя фаза: коммит + слияние в `dev`).
