# Команда /finish

Пред-коммитный чек-лист и коммит. Каждый пункт — проверить и **исправить**, если нарушено. Если
что-то не проходит — остановиться и сообщить, не коммитить.

## 0. Какая это фаза

Открыть `.specs/features/{WM-NN-…}/plan.md` текущей ветки → карта фаз:

| Ситуация | Итог `/finish` |
|---|---|
| Остались фазы после текущей | **коммит фазы** в ветке задачи, без слияния; пакет передачи (§5) |
| Текущая фаза — последняя | коммит фазы + спека `ЗАВЕРШЕНО` + **слияние в `dev`** (§6) |
| Ветка без номера (`chore/`, `fix/`, `docs/` без спеки) | один коммит + слияние в `dev` |
| Документационная ветка сценария B (`docs/WM-NN-…`) | коммит ресёрча/спеки/плана + слияние в `dev` |

## 1. Полный прогон

`npm run lint` + `npm run format:check` + `npm run build` + `npm run test:run` — **все четыре**,
ни один не заменяет другой (`rules.md` §6). Это единственный полный прогон за фазу; по ходу
работы гонялось только точечное. `format:check` упал → `npm run format` и перепроверить.

Документационный коммит (в диффе только `.md`, `.claude/`, `.research/`, `.specs/`, ни одного
файла `src/` и конфигов сборки) — прогоны пропускаются, и это озвучивается явно: «тесты не
запускались: кода в диффе нет».

## 2. Безопасность (`rules.md` §7)

- В диффе нет реальных `idInstance`/`apiTokenInstance` — в коде, тестах, `.env*`, ресёрчах и
  спеках.
- Нет `console.log` вне `import.meta.env.DEV`; URL запросов GREEN-API (в нём токен) не логируется.
- Нет `dangerouslySetInnerHTML`.

## 3. Код и стиль

- Цвета, кегли, радиусы — через `var()`; литералы только в `styles/tokens/`.
- Тесты на новое/изменённое есть (skill `frontend-patterns` §«Тестирование»).

## 4. Живые документы и документация

- **`spec.md`**: критерии фазы, подтверждённые доказательством, → `[x]`. Изменился скоуп — он
  уже здесь (правится по ходу, `rules.md` §3), а не собирается сейчас.
- **`plan.md`**: статус фазы в карте → `**VERIFIED** (ГГГГ-ММ-ДД)` при доказательстве, иначе
  `COMPLETED` с указанием, что не проверено. `tasks.md` — отметки.
- **Ресёрч эпика**: новые экраны/поведение → «Чек-лист сквозных сценариев»; на последней фазе —
  статус задачи в «Разбивке» → `в dev WM-NN@ГГГГ-ММ-ДД`.
- **README** актуален: что это, как запустить локально, что нужно от GREEN-API, ссылка на
  деплой, если есть.
- Принято решение (хранение учётных данных, деплой, скоуп) → ресёрч, `.docs/requirements.md`
  или «Зафиксированные договорённости» в `.claude/CLAUDE.md`.
- Проверено на живом инстансе то, что в skill `green-api` помечено «не проверено», → снять
  пометку и записать факт.

## 5. Коммит фазы

- Формат: `<тип>(область): описание на русском [WM-NN]` (`rules.md` §5). Ветки без номера — без
  `[WM-NN]`.
- **Один коммит на фазу**: код + тесты + живые документы вместе.
- **Без строки `Co-Authored-By`.**
- В карту фаз `plan.md` — короткий sha коммита (тем же коммитом: `--amend` сразу после).
- **Не последняя фаза** → дописать в `plan.md` §«Передача между фазами» пакет для следующей фазы
  (формат — в шаблоне) и предложить Диме: продолжить здесь или в новом чате после `/clear`.
- **Доводка закрытой фазы** (опечатка, забытый тест) — в **тот же** коммит через
  `git commit --amend`, пока следующая фаза не начата. Началась — отдельный
  `fix(область): доводка ФN [WM-NN]` с причиной.

## 6. Слияние в `dev` (последняя фаза задачи)

- `spec.md` → статус `ЗАВЕРШЕНО`, все критерии `[x]` (не подтверждённое — назвать явно, не
  отмечать молча).
- `git checkout dev` → `git merge --no-ff <ветка>`; ветку задачи не удаляем (`rules.md` §5).
  Конфликт при слиянии — остановиться и показать Диме, не разрешать молча.
- Подсказать дальше: эпик не закрыт → **`/epic-next`**; задача трогала GREEN-API → **что
  проверить Диме на живом инстансе** (`rules.md` §4).

## 7. Пуш — только Дима, и только в конце

- По задачам **не** пушим: `/finish` заканчивается коммитом или слиянием в `dev`.
- Когда Дима скажет «отправляем» — выдать в блоке кода команду пуша ветки `dev` с установкой
  upstream и напомнить, что PR `dev → main` он открывает в GitHub.
