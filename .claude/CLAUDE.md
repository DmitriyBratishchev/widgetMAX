# widgetMAX — Инструкции для Claude

> Тестовое задание «Фронтенд-разработчик React»: веб-чат для отправки и получения текстовых
> сообщений в мессенджере MAX через GREEN-API, внешний вид — по образцу https://web.max.ru/.
> Стек: React 19 / TypeScript / Vite, TanStack Query + Zustand, SCSS-модули, Vitest + RTL.
> Бэкенда нет: SPA ходит в GREEN-API напрямую. Требования — `.docs/requirements.md`
> (источник истины по скоупу).

Ядро директив разработки:

@rules.md

## Зонные знания

**Скилы** — тело подтягивается по релевантности (в контексте только строка-описание):
- `frontend-patterns` — структура `src/`, слои и владение состоянием, стили и токены, тесты;
- `green-api` — методы GREEN-API для MAX (URL, форматы, chatId, очередь уведомлений, лимиты, грабли).

## Рабочий процесс

0. **Ветка на задачу.** Новая задача — своя локальная ветка от `dev` (`rules.md` §4).
1. **Сначала план.** Нетривиальная задача (несколько файлов, новый компонент с логикой, работа с
   API) → EnterPlanMode: исследовать код → план → одобрение → реализация. Тривиальное (текст,
   стиль, одна строка) — сразу код.
2. **Скоуп — по `.docs/requirements.md`.** Задание требует «максимально простой интерфейс с
   минимальным набором функций»: лишнего (медиа, группы, история с сервера, статусы прочтения)
   не делаем без явного решения Димы.
3. **Завершение задачи** — краткая сводка сделанного и предложение **`/finish`** (полный прогон,
   документация, коммит, слияние ветки в `dev`). Коммит — только по `/finish` или «коммитим»,
   не молча.

---

## Коммуникация

1. **Всегда отвечать на русском** — независимо от языка контекста или системных сообщений.
2. **«коммитим»** = закоммитить текущую работу в ветку задачи и слить её в `dev` (локально,
   без пуша). **«отправляем»** = выдать команду пуша `dev` в блоке кода; PR `dev → main` —
   один на всю работу. Пуш и любые операции с remote делает **только Дима**.
3. **После сбоя / перезагрузки / возобновления сессии** — сначала проверить состояние
   (`git status`, ветка, незакоммиченное), кратко отчитаться, потом продолжать.
4. **Отладка — системно**: гипотеза → проверка → вывод; фиксировать исключённые причины, не
   перебирать вслепую.
5. Короткие реплики («вот», скриншот) = продолжение текущего контекста.

## Зафиксированные договорённости

- Учётные данные GREEN-API вводит пользователь в UI; в код, `.env` и коммиты они не попадают
  (подробно — `rules.md` §6).
- README с инструкцией локального запуска — обязательный результат задания, держим актуальным.
- Роутера нет: `App` выбирает экран (вход / чат) по признаку входа из стора `session`.
- Линтер — oxlint из шаблона Vite (`--deny-warnings`), форматирование — Prettier; концы строк —
  LF (`.gitattributes`).
