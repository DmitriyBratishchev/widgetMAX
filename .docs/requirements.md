## Постановка

Разработать пользовательский интерфейс для отправки и получения сообщений в **MAX**
(если выполнить для MAX невозможно — допускается WhatsApp или Telegram).

## Требования

1. Разработать пользовательский интерфейс для отправки и получения сообщений в MAX.
2. Использовать сервис **GREEN-API** — https://green-api.com/max
3. Реализовать отправку и получение **только текстовых** сообщений.
4. За прототип интерфейса взять внешний вид чата https://web.max.ru/
5. Интерфейс — **максимально простой**, с минимальным набором функций.
6. Отправка сообщений — методом
   [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/).
7. Получение сообщений — методом
   [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/)
   (ReceiveNotification + DeleteNotification).
8. Технология — **React**.

## Ожидаемый результат (сценарий приёмки)

1. Пользователь переходит на сайт чата и вводит свои учётные данные GREEN-API
   (`idInstance`, `apiTokenInstance`).
2. Пользователь вводит номер телефона получателя и создаёт новый чат.
3. Пользователь пишет текстовое сообщение и отправляет его получателю в MAX.
4. Получатель отвечает на сообщение в мессенджере MAX.
5. Пользователь видит ответ получателя в чате.
