# Research

Папка для исследований и обсуждений до фазы разработки.

## Процесс

1. **Ресёрч** — исследуем тему, собираем заметки в `.research/{topic-name}/research.md`
2. **Обсуждение** — возвращаемся к файлу, дополняем, уточняем
3. **Задача** — когда ресёрч созрел, Дима говорит «делаем» / «пиши спеку»
4. **Спека** — спецификация в `.specs/features/{WM-NN-задача}/`
5. **Код** — реализация по спеке

Ресёрч ≠ спека. Ресёрч — свободные заметки, вопросы, варианты. Спека — формальный документ для
реализации, который **ссылается** на ресёрч, а не дублирует его.

## Шаблон файла

```markdown
# {Название темы}

**Статус:** draft | in-progress | ready-for-task | archived
**Уровень:** задача | эпик | справочник
**Дата начала:** YYYY-MM-DD

## Контекст
Зачем исследуем, что хотим понять.

## Заметки
Находки, идеи, ссылки. Проверенные факты — с тем, чем проверены (команда, дата).

## Открытые вопросы
- [ ] ...

## Выводы
Итоги и решения Димы.

## Известные проблемы
Сопутствующие камни, обнаруженные при реализации. Включить в подходящую задачу.
- ...
```

Для эпика к шаблону добавляются разделы «Разбивка на задачи» и «Чек-лист сквозных сценариев»
(формат — `.claude/commands/research.md`).

### Метка `Уровень:`

Отвечает на вопрос «что вырастет из этого ресёрча» и определяет, какая команда его подхватит.
Её читают `/task-start` и `/epic-next` — **строго в шапке, до первого заголовка `##`**: в теле
«уровень» встречается в другом смысле (уровень риска, уровень тестов).

**Критерий выбора:** куски нарезки сами дробятся на фазы → **эпик**; куски и есть фазы →
**задача**; `WM-NN` из ресёрча не растёт вовсе → **справочник**.

| Уровень | Обязательная разбивка | Кто потребляет |
|---------|----------------------|----------------|
| **задача** | **карта фаз** — та же таблица, что ляжет в `plan.md` | `/task-start` (сценарий B) |
| **эпик** | **таблица задач `WM-NN`** | `/epic-next` |
| **справочник** | не нужна | никто: материал **цитируют** другие ресёрчи и спеки |

**Уровень объявляется при переводе в `ready-for-task`, а не на старте** — чем закончится ресёрч,
заранее неизвестно. Пока уровень не выбран, статус остаётся `in-progress`.

## Структура папок

Каждый ресёрч — своя папка: изображения (скриншоты web.max.ru, макеты) лежат рядом с текстом.

```
.research/
├── README.md
└── max-chat/
    ├── research.md
    └── web-max-layout.png
```

**Правила:**
- имя папки — kebab-case по теме;
- ресёрчи коммитятся (в них решения, которые не выводятся из кода);
- **учётные данные GREEN-API в ресёрч не пишем** — только заведомо фейковые
  (`1101000000` / `test-token`).
